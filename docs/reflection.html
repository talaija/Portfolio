Talaija Harris Assignment Reflection

Comparing XML website vs Word Press Website.

This is my Word Press Website.

When using xml to code the website with HTML I think the most significant challenge for me as a new learner was navigating how to implement div elements, css, remembering to add/commit/ push and ensuring the code does not “break”. When using Penn State Word Press one of the most significant challenges for me was inputting images as transferring the code over from xml was pretty straight forward but inputting images and fixing format took a bit of work. When using xml the advantage I think is the nicest is you are able to save as you go and refresh your browser so that you can quickly and easily see how your changes look. As for word press I think it has an advantage style wise it seems to be simpler and easier to play around with different style ideas, nav bar ideas, and photos have a built in caption element. Challenges that arise when modifying layout using XML that I noticed was you have to make sure you're very precise especially when adding in a nav bar to ensure that it flows nicely from page to page making sure not to skip over any pages. Changing the layout was a little bit tricky as well for word press because it already had built in titles, and layout changed when code was brought over from XML but overall it becomes understandable when you go through the preview mode to make sure everything looks well on the website. I think the skills that are most necessary to learn and develop these sites is a clear baseline understanding of HTML, CSS, Github, and Wordpress. These are all necessary because they each work together to build the websites from using HTML, and CSS to design the website and its content. As well as using Github, and wordpress to make these websites come to life for viewing. I want to learn to improve my CSS skills. I did lots of research on CSS but I like it because it allows you to customize the website in a fun, interactive, and unique way.
